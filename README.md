# Юридический навигатор — Telegram Mini App

Фронтенд ассистента по корпоративному юридическому руководству. Тонкий клиент: своей модели, своего промпта и своего поиска здесь нет — приложение отправляет вопрос в n8n и рисует то, что вернул workflow.

**Открыть:** https://knyazkovstudios1.github.io/legal-navigator-miniapp/

## Два режима

| Режим | Когда | Что происходит |
|---|---|---|
| Демонстрационный | На GitHub Pages — серверных функций тут нет | Ответы берутся из `demo-responses.json`. Файл сгенерирован прогоном **настоящих** Code-нод n8n (guardrail и визуализация), поэтому интерфейс ведёт себя ровно так же, но без живого поиска по Qdrant |
| Боевой | На Vercel с заданными переменными окружения | Работает функция `api/ask.js`: проверяет подпись `initData` и проксирует запрос в n8n |

Демонстрационный режим включается сам, когда `api/ask` отвечает 404, и честно объявляет о себе баннером наверху.

## Три ветки поведения

- **А** — прямой ответ со ссылкой на конкретный пункт руководства.
- **Б** — требуется действие: готовится черновик письма, отправка происходит **только** после подтверждения человеком в чате Telegram. Приложение получает ответ сразу, до паузы, и показывает статус ожидания.
- **В** — прямого основания в документе нет: вопрос передаётся юристу. Визуализация в этой ветке не показывается вовсе — график рядом с «подтверждения в базе нет» читался бы как ответ.

## Боевой запуск на Vercel

```bash
npx vercel --prod
```

Затем в Settings → Environment Variables:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен из BotFather |
| `N8N_CHAT_URL` | Production Chat URL ноды Chat Trigger |

Переменную `ALLOW_ANONYMOUS` в продакшене не задавайте — она отключает проверку подписи.

Токен бота живёт только в переменных окружения. В Code-ноду n8n его класть нельзя: исходник ноды выгружается в экспорт workflow дословно.

## Подключение к боту

BotFather → `/mybots` → бот → Bot Settings → Menu Button → Configure menu button → вставить URL → подпись `⚖️ Навигатор`.

Свой `setWebhook` на бота ставить не нужно: Telegram допускает один вебхук на бота, и это сломает согласование из n8n. Кнопка меню вебхука не требует.
